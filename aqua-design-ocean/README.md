# 魚缸先生｜海水缸（原海洋版）

本機預覽：<http://127.0.0.1:3100/public/demos/aqua-design-ocean/>

第三套獨立設計，以深海藍、青綠與珊瑚橘呈現珊瑚礁、海水與礁岩的層次。首頁採滿版海景，搭配緩慢水光、氣泡與線條魚群。繁體中文介面，保留魚缸先生品牌。

## 互動

- 獨立海洋入場：海光與氣泡、珊瑚線條與水波光圈、品牌浮現，最後呈現去背的反白 Logo（`mr-fish-tank-logo-light.png`，帶水光與微光陰影），再由海景向上揭開首頁。Logo 於 4.15–5.25 秒浮現、停留至 6.8 秒，退場 0.8 秒。
- 每次進入頁面自動播放，可跳過、按 Escape 或重播。背景頁籤會暫停；減少動態偏好不自動播放，手動重播則呈現短暫靜態畫面。
- 三張海洋首頁圖切換。
- 水中互動特效（`ocean-fx.js`／`ocean-fx.css`）：首頁 WebGL 水面折射（滑鼠劃過留下水紋、點擊落下水滴、偶爾自然滴水）、游標氣泡尾跡、點擊水波圈＋氣泡爆發、跟隨的泡泡游標（滑過可點元素會放大）、聯絡區會避開游標的線條魚群、作品／珊瑚圖片的水下光斑。右下角「水中特效」可開關並記住選擇（旁邊是深藍模式鈕）；減少動態偏好時完全不啟動，觸控裝置不顯示游標類特效。
- 枝狀、花朵型與柔珊瑚三組設計靈感，支援點選與方向鍵切換。
- 海洋概念分類、詳情彈窗與服務條件帶入。
- 珊瑚礁景、白沙潟湖、柔珊瑚花園三種 AI 生圖條件；海水魚或不放魚可選。
- 日夜海洋光境模擬、FAQ、三步諮詢需求摘要。
- 深藍模式（`deep-sea.css`）：日夜光境切到「深藍」或按右下角月亮鈕，整個網站以 1.2 秒轉場沉入夜海，並記住選擇；預約彈窗維持白底。深藍模式下會出現發光浮游生物：滑鼠劃過、點擊或快速捲動都會攪動海水讓牠們亮起來，游標尾跡變成冷光、點擊變成發光水波，聯絡區魚群也帶冷光。減少動態偏好時只切換配色，不顯示浮游生物。
- 三版本的右上角可切換水草缸、純魚缸和海水缸；純魚缸保留原有繁中／日文切換。
- 響應式排版與減少動態偏好。

## 生圖與圖像

共用 `/api/aqua-design` 與本機 Z-Image。海洋造景使用新增的 `reef`、`lagoon`、`softcoral` 與 `marine` 選項，後端組成海水珊瑚缸提示；原始版與日式版的淡水提示保持相容。`scripts/check-aqua-prompts.mjs` 檢查原提示回歸、海洋選項、不放魚與錯誤配對。

本頁三張設計影像由內建 ImageGen 製作，原圖直接複製到 `assets/`，完整提示與來源紀錄見 [image-prompts.md](assets/image-prompts.md)。所有影像都是概念示意，非施工案例或生物品種辨識資料。諮詢摘要僅顯示在頁面，不儲存或送出。

## 本機啟動

網站：`HOST=127.0.0.1 PORT=3100 node server.js`。

AI：`./scripts/start-aqua-image.sh`。沿用既有本機模型與忽略追蹤的設定檔，不需下載新模型。
