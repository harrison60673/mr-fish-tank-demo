# 魚缸先生｜日本商務設計版本

本機預覽：<http://127.0.0.1:3100/public/demos/aqua-design-jp/>

採白底、墨藍、朱紅點綴，明朝字體標題、編號與細線分隔，依服務與諮詢需求整理資訊。預設日文，右上角可切換繁體中文；語言選擇會保存在目前瀏覽器。

## 版本保存

- 修改前版本已存入本機 Git，commit `56f3479`，tag `aqua-nature-v1`。
- 新設計分支：`design/japanese-business`。
- 自然風格版保留在 `../aqua-design/`，頁面右上角與頁尾可切換比較。
- 不含 `.env`、詢問資料、本機生成服務設定。沒有設定遠端 repository 或推送。

## 互動與功能

- 三組首頁照片切換、設計參考分類、作品詳情彈窗。
- 四種服務帶入三步諮詢，頁面完成需求摘要。
- 四步規劃流程、日夜照明模擬、常見問題展開。
- 獨立日式入場：和紙底、水景方框逐筆描線、水紋與植物墨線、朱紅魚印與品牌落款，再由左右紙幕展開首頁。主段 3.9 秒、退場 0.65 秒，與原始錦鯉動畫分開。
- 每次進入頁面自動播放，可跳過、按 Escape 或從「觀看品牌動畫」重播。背景頁籤會暫停；減少動態偏好不自動播放，手動重播則呈現短暫靜態畫面。
- 共用原版本本機 Z-Image API；本版本的 `designer.js` 加入多語系狀態與摘要，維持生成條件、下載與帶入諮詢功能。
- `translations.js` 集中管理日文翻譯，`i18n.js` 處理文字、輔助標籤、選項、頁面標題及動態內容。切換語言時保留表單值與使用者輸入；預算明確標示台幣。
- 手機選單、響應式排版、鍵盤操作、減少動態偏好。

## 本機啟動

在專案根目錄啟動網站：`HOST=127.0.0.1 PORT=3100 node server.js`。AI 生圖另啟動 `./scripts/start-aqua-image.sh`。本機 Z-Image 的設定與模型位置沿用自然版本。

圖像共用 `../aqua-design/assets/`。參考網站影像仍為概念展示，沒有將其宣稱為魚缸先生完成的客戶案例。諮詢僅於當前頁面顯示摘要，不儲存或寄送。
